CAPSTONE 59 — Personal Productivity System with Notion and Obsidian

Files: index.html (structure), style.css (design), script.js (functionality). Keep all three in the same folder and open index.html in a browser. For GitHub Pages, upload all three to the repository root and enable Pages from main / (root).

This is a working frontend prototype. Data is stored in browser localStorage. Notion/Obsidian sync and scheduled cloud automation require secure API setup and a backend. Never put API keys or passwords in frontend JavaScript.
